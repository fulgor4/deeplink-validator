Deeplink Validator

Checks a campaign link for the problems that make the Walmart iOS app open and then bounce to web. Validation runs in your browser. With “Trace redirects” on, the link is also sent to this tool's server so it can follow the redirect chain.

Link to validate

Paste the campaign link (click2cart, pgbuynow, …) or the goto.walmart.com link; redirects are followed for you.

The app-side simulation is a port of ImpactLink.manipulate(), walmartSchemeURL and UniversalLinkComponents from glass-app. Route matching is a heuristic: the [DL-DEBUG] canRoute= log from a debug build is the ground truth.
